# ml-course-work

Курсовая работа по классическому машинному обучению. Проект посвящен анализу химических соединений и построению моделей для прогнозирования показателей эффективности и безопасности потенциальных лекарственных препаратов.

## Описание проекта

В работе используются данные о химических соединениях из файла [`data/compounds.xlsx`](data/compounds.xlsx). Для соединений представлены числовые химические дескрипторы и целевые показатели:

- `IC50, mM` - показатель противовирусной активности;
- `CC50, mM` - показатель цитотоксичности;
- `SI` - индекс селективности, рассчитываемый как отношение `CC50 / IC50`.

Основная цель проекта - исследовать данные, сравнить разные модели машинного обучения и выбрать наиболее качественные решения для задач регрессии и классификации.

В рамках работы решаются следующие задачи:

- регрессия для `IC50`;
- регрессия для `CC50`;
- регрессия для `SI`;
- классификация: `IC50` выше медианы выборки;
- классификация: `CC50` выше медианы выборки;
- классификация: `SI` выше медианы выборки;
- классификация: `SI > 8`.

## Используемые подходы

Для анализа и моделирования используются:

- разведочный анализ данных и визуализация распределений;
- проверка пропусков, выбросов и корреляций;
- стандартизация числовых признаков;
- заполнение пропущенных значений медианой;
- удаление признаков с нулевой дисперсией;
- сравнение линейных моделей, ансамблей деревьев, градиентного бустинга и KNN;
- подбор гиперпараметров;
- оценка регрессии по `MAE`, `RMSE`, `R2`;
- оценка классификации по `accuracy`, `precision`, `recall`, `F1`, `ROC-AUC`.
